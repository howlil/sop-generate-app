4. After migration, add the BEFORE UPDATE trigger for SOP BERLAKU -> TTESignature validation. Create a separate migration:
   ```bash
   cd server && npx prisma migrate dev --create-only --name add_sop_berlaku_trigger
   ```
   Then edit the generated SQL file to add:
   ```sql
   DELIMITER $$
   CREATE TRIGGER check_sop_berlaku_has_tte
   BEFORE UPDATE ON `SOP`
   FOR EACH ROW
   BEGIN
     IF NEW.status = 'BERLAKU' THEN
       IF NOT EXISTS (
         SELECT 1 FROM `TTESignature` WHERE `sopId` = NEW.id
       ) THEN
         SIGNAL SQLSTATE '45000'
           SET MESSAGE_TEXT = 'SOP cannot be set to BERLAKU without a TTESignature';
       END IF;
     END IF;
   END$$
   DELIMITER ;
   ```
   Then run `cd server && npx prisma migrate dev` to apply it.

5. Verify compilation: `cd server && npx tsc --noEmit` (or `npx nest build` if tsc alone fails due to NestJS config).
